# Voice Question Answering System

## Description

Voice Question Answering System is a simple speech and language processing application that allows users to ask questions using their voice.

The application converts speech into text, identifies the question, provides an answer, and converts the answer back into speech.

## Technology Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- Natural Language Processing
- Speech Processing

## Features

- Voice input
- Speech-to-text conversion
- Question answering
- Text-to-speech conversion
- Voice output

## Requirements

- Python 3.x
- VS Code
- Working microphone
- Speakers or headphones
- Internet connection

## Installation

Install the required libraries:

pip install SpeechRecognition PyAudio pyttsx3

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install the required libraries.
4. Run:

python app.py

5. Speak a question into the microphone.
6. The application converts the question into text.
7. The application displays the answer.
8. The computer speaks the answer.
